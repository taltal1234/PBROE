# Is the P/B ROE Model More Than Value? Evidence from the Pakistan Stock Exchange

Author: Ahmed Tallal Bajwa

The paper is `paper/Bajwa_PB_ROE_Pakistan.pdf`; its LaTeX source is `paper/Bajwa_PB_ROE_Pakistan.tex`.

## Folder layout

| Folder | What is in it |
|---|---|
| `config.py` | every setting (sample, filters, sectors, portfolio and test choices, paths) |
| `run_all.py` | runs steps 2 to 4 and builds the paper |
| `pipeline/` | numbered scripts, run in order |
| `src/` | code the scripts share: reading WRDS files (`utils.py`), the statistics such as Newey West and OLS residuals (`stats.py`), portfolio sorts (`portfolios.py`) |
| `requirements.txt` | Python packages |
| `data/raw/` | WRDS downloads, never edited by hand |
| `data/processed/` | monthly panel, long short returns, factors, regression slopes |
| `results/tables/` | every result as csv |
| `results/figures/` | figures used in the paper |
| `paper/` | the paper: `.tex` source, `numbers.tex` and `tables/` (both generated by step 4), and the PDF |
| `reference/` | the earlier LUMS senior project report (kept on my computer, not on GitHub) |

## Steps

1. `pipeline/01_download_wrds.py` downloads Compustat Global data for every Pakistani company (active and inactive): company list, annual fundamentals, daily prices, KSE100 index. Run it in Spyder with the Run button (set `CHECK_ONLY` at the top).
2. `pipeline/02_build_panel.py` builds the monthly panel: total returns, fundamentals used 4 months after fiscal year end, universe filters, and the monthly cross sectional regression of ln(P/B) on ROE whose residual is the signal.
3. `pipeline/03_backtest.py` forms quintile and sector tercile portfolios and computes long short returns, Newey and West t statistics, rank IC, hit rate against the chance rate, Fama and MacBeth regressions, factor alphas, subperiods and trading costs.
4. `pipeline/04_figures_tables.py` writes the figures, the LaTeX tables and `paper/numbers.tex`. Every number in the paper comes from this step; none is typed by hand.

After step 1, run `python run_all.py` to redo everything else.

## Risk free rate

`data/raw/sbp_tb_auctions.xlsx` is the State Bank of Pakistan's full Market Treasury Bill auction history
(https://www.sbp.org.pk/ecodata/tb.xlsx). Step 3 reads its "Old Format" sheet (1998 onward), takes the
3 month weighted average yield, averages it by month and uses it as the risk free rate for the market factor.
To update it, download the file again, save it under the same name and rerun `run_all.py`.

## Python version

Install the packages with `pip install -r requirements.txt`. Use pandas 3 or newer, which is what reproduces
the paper's numbers exactly. Sectors are sorted into terciles of small groups of firms (as few as 8), so some
stocks sit exactly on a tercile boundary. pandas 2 rounds those boundaries differently and puts a few of them
in the neighbouring tercile. Everything at the market level is the same under both versions; the within
sector results are not.

## Note on reading parquet files

If `pd.read_parquet` fails with `No module named 'pandas.api.internals'`, run `pip install -U pandas pyarrow` in the Anaconda terminal.
